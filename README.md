# 🌐 Personal Portfolio Website

A modern, responsive, and performance-focused **personal portfolio website** built to showcase my projects, skills, and journey as a developer.  
Designed with a clean **dark theme**, smooth animations, and a strong focus on user experience.

---

## ✨ Features

- ⚡ Modern UI with a professional dark theme  
- 🎨 Fully responsive (mobile, tablet, desktop)
- 🎞 Smooth animations using Framer Motion
- 🧩 Modular and reusable components
- 📂 Projects showcase with live demos & source code
- 👤 About section focused on skills and impact (no distractions)
- 🚀 Fast performance and optimized assets

---

## 🛠 Tech Stack

**Frontend**
- React.js / Next.js
- Tailwind CSS
- Framer Motion

**Other Tools**
- JavaScript (ES6+)
- Git & GitHub
- Vite / Next.js (based on setup)
